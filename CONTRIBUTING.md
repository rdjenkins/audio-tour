# Contributing to Audio Tour

Thank you for your interest in contributing to the Audio Tour code (part of the Celtic Quiet Places project)! We welcome contributions of all kinds, including bug fixes, new features, documentation improvements, and more.

## How to Contribute

1. **Fork the repository** and create your branch from `main`.
2. **Make your changes** with clear, descriptive commit messages.
3. **Test your changes** to ensure they work as expected and do not break existing functionality. If you are able please also check the changes in the [Capacitor example](https://github.com/rdjenkins/audio-tour-player-capacitor-example) on native devices
4. **Submit a pull request** with a clear description of your changes and why they are needed.

## Code of Conduct

Please be respectful and considerate in your communications and contributions. We are committed to fostering a welcoming and inclusive environment for everyone.

## Reporting Issues

If you find a bug or have a feature request, please [open an issue](https://github.com/rdjenkins/audio-tour) and provide as much detail as possible.

## Coding Guidelines

- Follow existing code style and conventions. The priority is to make the code sustainable and usable by future coders.
- Write clear, concise comments where necessary.
- Keep pull requests focused and minimal.
